馬町珈琲 Instagram 自動投稿キット
================================

このzipを展開すると、次の2つのフォルダがあります。どちらも GitHub のリポジトリ
umamachicoffee/umamachicoffee.github.io の「一番上の階層」にアップロードします。

  instagram/   … 画像・プログラム・説明書（約60ファイル）
  .github/     … 自動実行の設定（2ファイル）※名前が「.」で始まるため隠れて見えないことがあります

このテキストファイル自体はアップロード不要です。

手順の詳細は instagram/autopost/README.md と 01_アップロード手順.md を読んでください
（PCではテキストエディタやブラウザで開けます。アップロード後は GitHub 上できれいに表示されます）。

重要
- アップロードには、リポジトリの Write 権限が必要です（組織オーナーに付与を依頼）。
- トークンなどの秘密の値は、このキットのどこにも書かれていません。GitHub の Secrets にだけ入れてください。
- 10/5〜10/12 は Business Suite の予約投稿があるため、自動投稿のスイッチ（IG_AUTOPOST_ENABLED）を
  true にするのは 10/13 以降にしてください。
