# リール用の動画置き場（いまは空）

- ここに MP4 を置き、`instagram/autopost/content.py` の `REELS` の `video` にファイル名を書くと、リールの投稿対象になります。
- 動画1本ごとにリポジトリ（公式サイトと同じ場所）が重くなり、**消しても履歴に残り続けます**。
  - 1本 **20MB 以下** を目安に（GitHub のブラウザからのアップロードは1ファイル25MBまで、100MB以上は保存不可。リポジトリ全体は1GB以下が目安）。
  - 縦長 1080x1920、MP4（H.264 / AAC）、数十秒程度にしてください。iPhone の .MOV（例：IMG_4940.MOV＝118MB）はそのままでは置けません。
- 黒板（Wi-Fi情報）・第三者の絵画・はっきり写った人物が**1コマでも**映る動画は使わないでください。
  - 公式サイトの `assets/video/umamachi-reel.mp4` には黒板と額装絵画が映るため、リールには使えません。
- 音楽・スタンプは API では付けられません（必要な場合は Instagram アプリから手動で投稿）。
