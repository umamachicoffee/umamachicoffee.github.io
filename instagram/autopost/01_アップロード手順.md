# 01 アップロード手順（GitHub のブラウザ画面だけで行います）

## 0. 事前に必要なこと：リポジトリへの「書き込み権限（Write）」

いまの俵原さんのアカウントは組織（umamachicoffee）の **メンバー（読み取りのみ）** なので、このままではアップロードできません。
**組織のオーナー（Owner）の方に、次の操作をお願いしてください。**

1. https://github.com/umamachicoffee/umamachicoffee.github.io を開く
2. 上のタブの **Settings**（歯車）→ 左メニュー **Collaborators and teams**（または「Collaborators」）
3. **Add people** → 俵原さんの GitHub アカウント名を入力して選ぶ
4. 役割（role）で **Write** を選んで **Add** をクリック

あわせて、同じ Settings の中で次も確認してもらうと確実です（オーナーしか変更できない場合があります）。

- 左メニュー **Actions → General**
  - 「Actions permissions」が **Allow all actions and reusable workflows**（または GitHub 公式アクションを許可）になっている
  - 一番下の「Workflow permissions」が **Read and write permissions** になっている
    （ワークフローに `permissions: contents: write` と書いてありますが、組織の設定で禁止されていると保存（push）に失敗します）
- 左メニュー **Secrets and variables → Actions** を俵原さんが開けること（開けない場合は、オーナーに Secrets 登録を代わりにお願いする）

## 1. zip を展開する

1. `umamachi-ig-autopost.zip` をダブルクリックして展開します。
2. 展開したフォルダの中に、次の2つがあることを確認します。
   - `instagram` フォルダ
   - `.github` フォルダ（名前が「.」で始まるので、**普段は見えないことがあります**）
     - **Mac**：Finder でそのフォルダを開き、`command` + `shift` + `.`（ピリオド）を押すと表示されます
     - **Windows**：エクスプローラーの「表示」→「隠しファイル」にチェック
3. `UPLOAD_CHECKLIST.txt`（同じ場所）に、アップロードするファイルの一覧があります。

## 2. `instagram` フォルダをアップロード

1. ブラウザ（**Chrome または Edge 推奨**。フォルダのドラッグに対応しています）で
   https://github.com/umamachicoffee/umamachicoffee.github.io を開き、ログインします。
2. ファイル一覧の上にある **Add file** ボタン → **Upload files** をクリック。
3. 展開したフォルダから **`instagram` フォルダそのもの**を、「Drag files here…」の枠にドラッグ＆ドロップします。
   - 中身だけでなく **フォルダごと** ドラッグすると、`instagram/autopost/…` のようにフォルダの形が保たれます。
   - 画面に `instagram/autopost/config.py`、`instagram/generated/feed/f01-blend.jpg` のように表示されればOK。
   - 一度にアップロードできるのは100ファイルまで、1ファイル25MBまでです。このキットはその範囲に収まっています。
4. 下の「Commit changes」欄
   - 1行目（メッセージ）：`Instagram自動投稿キットを追加` など
   - **Commit directly to the `main` branch** を選ぶ
   - **Commit changes** をクリック
5. 数十秒〜数分でアップロード完了。ファイル一覧に `instagram` フォルダが出ます。

## 3. `.github` フォルダ（ワークフロー）をアップロード

### 方法A：ドラッグでアップロード（まずはこちら）

1. もう一度 **Add file → Upload files**
2. **`.github` フォルダそのもの**をドラッグ＆ドロップ
3. 画面に `.github/workflows/instagram-autopost.yml` と `.github/workflows/instagram-generate-overlays.yml` の2つが出ることを確認
4. **Commit directly to the main branch** → **Commit changes**

### 方法B：うまくいかないとき（ファイルを手で作る）

隠しフォルダがドラッグできない、アップロード後に `.github` が見当たらない、などの場合はこちら。

1. リポジトリのトップで **Add file → Create new file**
2. 上部の名前欄に、**半角で次のとおり入力**します（`/` を打つと自動でフォルダに変わります）
   ```
   .github/workflows/instagram-autopost.yml
   ```
3. PC で、展開したフォルダの `.github/workflows/instagram-autopost.yml` を
   **メモ帳（Windows）/ テキストエディット（Mac）** で開き、**全部選択してコピー**
   （Mac のテキストエディットは「フォーマット」→「標準テキストにする」にしてから）
4. GitHub の大きな入力欄に **貼り付け**
   - 先頭が `# 馬町珈琲 Instagram 自動投稿` で始まり、行頭の空白（字下げ）が崩れていないこと
5. 右上 **Commit changes…** → **Commit directly to the main branch** → **Commit changes**
6. 同じ手順で、2つ目のファイルも作ります
   ```
   .github/workflows/instagram-generate-overlays.yml
   ```

## 4. 確認

1. リポジトリ上部の **Actions** タブを開き、左側に
   - **Instagram auto post**
   - **Instagram generate overlays**
   の2つが表示されていればOK。
   （「Workflows aren't being run on this repository」などと出たら、**I understand… enable them** を押して有効にします）
2. 5〜10分ほど待ってから、ブラウザで次のURLを開き、画像が表示されることを確認します。
   - https://umamachicoffee.jp/instagram/generated/feed/f01-blend.jpg
   - https://umamachicoffee.jp/instagram/generated/story/s01-hours.jpg
3. https://umamachicoffee.jp/ のトップページが今までどおり表示されることも確認してください。
