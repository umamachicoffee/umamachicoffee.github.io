# 03 テスト手順

**本番アカウントへの投稿は、必ずオーナー（俵原さん）の許可を得てから、1回だけ行います。**

## 前提

- [01_アップロード手順.md](01_アップロード手順.md) が終わり、
  https://umamachicoffee.jp/instagram/generated/feed/f01-blend.jpg が表示される
- [02_Meta設定ガイド.md](02_Meta設定ガイド.md) で Secrets（`IG_ACCESS_TOKEN` / `IG_USER_ID`）を登録済み
- 変数 `IG_AUTOPOST_ENABLED` は **`false`**

## ステップ1：確認だけの実行（ドライラン。投稿しません）

1. リポジトリの **Actions** タブ → 左の **Instagram auto post**
2. 右側の **Run workflow** ボタン → ブランチは `main` のまま
3. **「確認だけ（投稿しない）」にチェックが入っていること**を確認（最初から入っています）
4. 緑の **Run workflow** をクリック
5. 少し待つと一覧に実行が出るので、クリック → **post** → **Post to Instagram** を開いてログを見る

確認するところ：

- `[DRY RUN] フィード: 投稿予定 #0 f01-blend` のように、投稿予定の画像とキャプションが表示されている
- `公開URLの確認: OK` になっている（NG のときはアップロード直後なので数分待つ、またはファイルの場所を確認）
- 実行結果が緑のチェック ✅

ドライランでは Instagram に一切接続せず、state.json / post_log.txt も変わりません。

## ステップ2：オーナーの許可を得て、1回だけ本番投稿（フィードのみ）

> **注意：10月5日〜12日は Business Suite の予約投稿があります。** この期間にテスト投稿すると、その日は投稿が2件になります。
> 可能なら **10月13日以降** に行ってください。

1. **Actions → Instagram auto post → Run workflow**
2. **「確認だけ（投稿しない）」のチェックを外す**
3. 「投稿する種類」で **feed** を選ぶ
4. 「force」はオフのまま
5. **Run workflow**
6. 1〜2分後、Instagram アプリで @umamachi.coffee にフィード投稿（f01 馬町ブレンド）が出ていることを確認
7. リポジトリの `instagram/autopost/post_log.txt` に `[OK] feed #0 f01-blend media_id=…` が追記され、
   `state.json` の `feed` の `last_posted_date` がその日の日付になっていれば成功

うまくいかないとき：赤い ❌ の実行を開き、`[FAIL]` の行を確認（[04_運用ガイド.md](04_運用ガイド.md) の「失敗したとき」）。

ストーリーズも試したい場合は、別の日に同じ手順で「投稿する種類」を **story** にします。

## ステップ3：毎日の自動投稿をオンにする（10月13日以降）

1. **Settings → Secrets and variables → Actions → Variables** タブ
2. `IG_AUTOPOST_ENABLED` の鉛筆（編集）→ Value を **`true`** → **Update variable**

- 翌朝 9:00（日本時間）ごろから自動投稿が始まります。**GitHub の定時実行は混雑で数時間遅れることがあります。**
  「まだ投稿されていない」と思っても、**定刻＋4時間は待ってください。** 遅れだと思って手動実行すると、
  直後に本来の定時実行が動いて同じ日に2回投稿になる事故が実際に起きています。
  （この仕組みは同じ日の同じ種類を自動でスキップしますが、手動で `force` をオンにすると防げません）
- テスト投稿をした日に `true` にした場合、その日のフィードは「投稿済み」としてスキップされ、ストーリーズだけが投稿されます。
- Business Suite の予約投稿と重ならないよう、**Business Suite 側の予約は 10/12 分まで** にしてください。
